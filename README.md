# Cancer and the Cell Cycle: TCGA figures

The code and data behind every TCGA figure in the *Cancer and the Cell Cycle*
lectures (University of Sussex, 2026). Each figure is a
[marimo](https://marimo.io) notebook: run it, read the code, change a
definition and watch the figure change.

| Notebook | Lecture | Question |
|---|---|---|
| `01_oncogene_landscape.py` | 2 | Which oncogenes drive which cancers? |
| `02_oncoprint_luad.py` | 2 | Why does a lung tumour carry only one driver? |
| `03_lollipops.py` | 2, 3 | Where are KRAS, BRAF, RB1 and TP53 hit? |
| `04_rb_pathway.py` | 2 | How do tumours break the Rb pathway? |
| `05_tp53_across_cancers.py` | 3 | How often is TP53 mutated? |
| `06_cdk_drivers_need_p53_gone.py` | 3 | Do tumours driving CDK2 lose p53? |
| `07_genomes_come_apart.py` | 3 | Does losing p53 destabilise the genome? |
| `08_genome_doubling.py` | 3 | How common is a doubled genome, and where does it go? |
| `09_chromosome_arms.py` | 3 | Which chromosome arms are gained or lost? |
| `10_gene_dosage_8q.py` | 3 | Does an extra arm mean extra RNA? |

## Getting started

You need [uv](https://docs.astral.sh/uv/getting-started/installation/), which
installs Python and every package for you.

```bash
git clone https://github.com/Helfrid/ccc-tcga-figures.git
cd ccc-tcga-figures
uv sync
uv run marimo edit notebooks/05_tp53_across_cancers.py
```

The notebook opens in your browser. Cells re-run by themselves when you
change something they depend on. `uv run marimo edit notebooks` opens a file
browser over all ten.

Every notebook ends with **Try this**: small questions that need a few
lines of code.

## The data

`data/` holds a small extract (16 MB) of the TCGA PanCancer Atlas, about
10,000 tumours from 33 cancer types, so the notebooks need no database:

| File | What it holds |
|---|---|
| `patients.parquet` | cancer type; whether the patient has mutation calls |
| `mutations.parquet` | every protein-changing mutation (MC3 public calls) |
| `copy_number.parquet` | gene-level log2 copy ratio, ~60 cancer and cell cycle genes |
| `genome_altered.parquet` | fraction of genes with a changed copy number |
| `arms.parquet` | median log2 copy ratio of each chromosome arm |
| `ploidy.parquet` | ploidy, genome doublings and purity (ABSOLUTE) |
| `genes.parquet` | protein-coding genes with their chromosome arm |
| `expression_brca.parquet` | breast tumours: expression of 8q genes and 1,500 others |

`scripts/build_extract.py` makes these files from the full database,
[tcga-db](https://github.com/Helfrid/tcga-db), which also holds expression
for all genes, survival, mutational signatures and GTEx normal tissues.
Build it yourself to go further.

Definitions shared by the notebooks (hotspots, thresholds for amplified and
deleted) are in `notebooks/tcga.py`.

## Sources

The data are open access, from the [UCSC Xena](https://xenabrowser.net)
TCGA PanCancer Atlas hub:

- mutations: MC3 (Ellrott et al. 2018, *Cell Systems* 6: 271);
- copy number: Broad SNP6, gene level;
- ploidy and genome doubling: ABSOLUTE (Taylor et al. 2018, *Cancer Cell*
  33: 676);
- expression: UCSC Toil RNA-seq recompute (Vivian et al. 2017, *Nature
  Biotechnology* 35: 314).

The results here are based on data generated by the TCGA Research Network:
https://www.cancer.gov/tcga.
